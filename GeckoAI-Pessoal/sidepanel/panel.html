IA

Configurações

Esta edição usa sua API diretamente. A cobrança é feita pelo provedor, conforme seu plano. Não é necessária uma licença do GeckoAI original.

GitHub conecta seus repositórios. Supabase e Vercel são opcionais. Cada serviço usa seu próprio token pessoal, salvo somente nesta instalação.

Chaves de API, tokens e histórico ficam neste navegador (chrome.storage.local). Nada é enviado a serviços além da API de IA escolhida e das integrações que você conectar. Com o seu ChatGPT conectado, os pedidos vão direto deste navegador para a OpenAI.

Skills

Instruções de especialista que ficam dentro do seu projeto. Depois de instalada, a IA segue a skill sozinha nos pedidos daquele tema.

As skills ficam na pasta .agents/skills do seu repositório e não mudam nada no site. São guias públicos e muito usados, adaptados para projetos da Lovable; a licença de cada um vai junto.

Sincronizar schema

Isto dá à IA o retrato real do seu banco no Lovable Cloud. É só leitura (SELECT) — não altera nada.

  1. Copie o SQL e rode no editor de SQL do Lovable.
  2. Clique em Export CSV lá no Lovable (não precisa abrir o arquivo).
  3. Envie o arquivo aqui — eu guardo em docs/DB_SCHEMA.json.
